# FreeLOOIBot
Свободнобесплатный порт LOOI на esp32 (пока что просто затычка для того чтобы приложение работало)

Я захотел себе EMO, но у меня нету столько денег, а переносить прошивку в эмулятор вечное безумие. Смотря на аналоги я понял что всё ПО LOOI и так доступно, звчем тогда мне покупать зарядку на колёсиках за 20к?

Чуть позже будет добавленна серво для поворота бошки, 2 моторчика для передвижения и какой нибудь датчик чтобы робот не падал со стола
